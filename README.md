## 📂 Prompt Collection

### 1️⃣ System Understanding Prompt
**File:** [`prompt-for-coding-agent-to-understand-the-codebase.md`](prompt-for-coding-agent-to-understand-the-codebase.md)

**Purpose:** Generate complete, single-document system documentation from existing codebases

**Use Case:**
- Reverse-engineering legacy systems
- Creating technical documentation for existing applications
- Onboarding AI agents to complex projects
- Establishing source-of-truth documentation

**Output:** Comprehensive `SYSTEM_UNDERSTANDING.md` covering architecture, APIs, database, deployment, and more

---

### 2️⃣ Spec-Kit Input Form
**File:** [`speckit-form.md`](speckit-form.md)

**Purpose:** Structured template for gathering project requirements

**Use Case:**
- Collecting project specifications systematically
- Standardizing requirement gathering
- Preparing inputs for AI-driven project generation

**Output:** Completed project requirements ready for specification generation

---

### 3️⃣ Spec-Kit Generation Prompt
**File:** [`speckit-prompt.md`](speckit-prompt.md)

**Purpose:** Transform requirements into five structured specification documents

**Use Case:**
- Generating project constitutions and principles
- Creating detailed technical specifications
- Building implementation plans and task lists
- Producing AI agent execution instructions

**Output:** Five-part specification:
- `/speckit.constitution` – Code quality & testing standards
- `/speckit.specify` – Product specification
- `/speckit.plan` – Implementation architecture
- `/speckit.tasks` – Step-by-step task breakdown
- `/speckit.implement` – Final execution instructions

## 🚀 Quick Start

### Using the System Understanding Prompt

```bash
# 1. Copy the prompt content
cat prompt-for-coding-agent-to-understand-the-codebase.md

# 2. Paste into your AI coding agent (GitHub Copilot, Cursor, etc.)

# 3. AI will analyze your codebase and generate SYSTEM_UNDERSTANDING.md
```

### Using the Spec-Kit Framework

```bash
# 1. Fill out the input form
# Open and complete: speckit-form.md

# 2. Provide filled form + generation prompt to your AI agent
cat speckit-form.md speckit-prompt.md

# 3. AI generates 5 structured specification documents
```
